Your data & privacy

Entries are saved in this browser, on this device. This app has no account, analytics or server database. GitHub Pages hosts only the code, not the health records.

Private browsing, clearing website data, replacing a device or using a different browser can make entries unavailable. Back up regularly and keep backup files somewhere private.

Install Wellness Tracker

Install the app to launch from its own W icon, without having to open a browser tab. Installation depends on your browser and device.

A shortcut with a Chrome badge is not the same as an installed app. On Android, open the published site directly in Chrome, check the installation setup here, then choose Install app. Existing data stays with the website, but back up before reinstalling or clearing any browser data.

Separate from your other tracker

Wellness Tracker has its own records and settings. It doesn't read or change the data in Symptom Tracker or Life Tracker.

Start fresh

Permanently delete the records and profile saved for this app on this device. Make a backup first.
